# WMS 业务闭环模拟示例运行说明

## 环境

- .NET SDK 10.0+（本仓库所有示例使用 net10.0）
- 无需额外 NuGet 包，纯 BCL

## 运行

```bash
dotnet run
```

## 演示内容（对应 WMS.md 知识点）

用一段"仓库一天"的模拟，把 WMS 业务闭环跑一遍：

1. **收货** `Receive` — 货到登记为"待上架"（还不能拣货）
2. **上架** `Putaway` — 放到指定库位，库存变"可用"
3. **波次** `CreateWave` — 把 2 张出库单合并成一个拣货批次
4. **拣货** `PickFifo` — 按批次先进先出（FIFO）扣减：SO-001 先拣最早批次 B2407 再补 B2408
5. **发运** `Ship` — 过账扣库存、回传 ERP
6. **补货触发** — 可用库存低于安全库存 → 再走收货，形成闭环
7. **库存不足拦截** — 缺货时抛异常，防止超卖/负库存

建议动手改一改：新增一个批次收货再拣货看 FIFO 顺序；把拣货改成 FEFO（按效期/到期日排序）；给 `PickFifo` 加并发扣减演练（配合 Database 笔记的防超卖）。
